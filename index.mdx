Create a referral from your backend. Your customer receives an invitation to
complete their Delaware C Corporation in Expedite, while your team follows their
progress through the API or Partner Console.

<RequestExample>

```bash cURL wrap
EXPEDITE_API=https://api.expedite.now/api/partners/v1
INVITATION_KEY=atlas-labs-incorporation-001

curl "$EXPEDITE_API/incorporations" \
  --header "Authorization: Bearer $EXPEDITE_ACCESS_TOKEN" \
  --header 'Content-Type: application/json' \
  --header "Idempotency-Key: $INVITATION_KEY" \
  --data '{
    "externalReference": "atlas-labs-001",
    "email": "alex@example.com",
    "givenName": "Alex",
    "familyName": "Morgan",
    "companyName": "Atlas Labs"
  }'
```

```javascript JavaScript wrap
const response = await fetch("https://api.expedite.now/api/partners/v1/incorporations", {
	method: "POST",
	headers: {
		Authorization: `Bearer ${process.env.EXPEDITE_ACCESS_TOKEN}`,
		"Content-Type": "application/json",
		"Idempotency-Key": "atlas-labs-incorporation-001",
	},
	body: JSON.stringify({
		externalReference: "atlas-labs-001",
		email: "alex@example.com",
		givenName: "Alex",
		familyName: "Morgan",
		companyName: "Atlas Labs",
	}),
})
if (!response.ok) throw new Error(`Invitation failed: ${response.status}`)
const referral = await response.json()
console.log(referral.id)
```

```python Python wrap
import json
import os
from urllib.request import Request, urlopen

request = Request("https://api.expedite.now/api/partners/v1/incorporations", data=json.dumps({
    "externalReference": "atlas-labs-001",
    "email": "alex@example.com",
    "givenName": "Alex",
    "familyName": "Morgan",
    "companyName": "Atlas Labs",
}).encode(), headers={
    "Authorization": "Bearer " + os.environ["EXPEDITE_ACCESS_TOKEN"],
    "Content-Type": "application/json",
    "Idempotency-Key": "atlas-labs-incorporation-001",
})
with urlopen(request) as response:
    referral = json.load(response)
print(referral["id"])
```

## One referral, from invitation to EIN

<Steps>
	<Step title="Invite your customer">
		Send their name, email, and your customer reference. Keep the returned referral ID to connect their
		incorporation to your product.
	</Step>
	<Step title="Let the founder complete their application">
		The founder signs in, completes the forms, and signs their documents in Expedite. Your dashboard and API reflect
		the progress they have agreed to share.
	</Step>
	<Step title="Act on verified milestones">
		Receive a signed webhook when progress changes. Fetch the current status to learn when Delaware approves the
		company or the EIN is issued.
	</Step>
</Steps>
